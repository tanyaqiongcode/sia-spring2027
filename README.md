# 高级口译通关营 · 决胜 2027 春（SIA Advanced Interpretation, Spring 2027）

一套针对 **上海外语口译证书考试 · 英语高级口译**（笔试 + 口试一次通过）的完整备考系统，纯静态网站，托管于 GitHub Pages。目标：**2027 年 3 月笔试（预计）+ 2027 年 5–6 月口试（预计）**，从 2026-10-30 起约 20 周笔试冲刺 + 8 周口试特训。

> **在线访问**：https://tanyaqiongcode.github.io/sia-spring2027/

## 为什么做这个

- 高级口译是「及格线考试」：笔试 300 分拿 180，口试 8 段拿 6 段。备考决策全部围绕两条线展开，不追求满分。
- 网上备考信息散落在知乎、公众号、网盘里；GitHub 上没有成体系的高口备考仓库。本站把官方教材用法、真题策略、口试评分规则、开源工具核查整理成一条可执行路线。
- 口试「只放一遍 + 即刻开口」的纪律靠日常工具养成：内置**口译段落台**（播放一遍自动停 + 录音对比 + 及格制自评）。

| 页面 | 内容 |

## 「静态托管 + 动态体验」的架构

- 纯 HTML/CSS/JS，无框架、无后端、无构建步骤。
- `scripts/update_feeds.py` 每日抓取 BBC Global News / CNN 10 / Business Daily / FT中文网双语 RSS 生成 `data/latest.json`，由 GitHub Actions（`update-feeds.yml`，UTC 00:40）自动提交。
- 资源页 GitHub 工具星数通过 GitHub API 实时读取。
- 打卡、听写、口译自评统计存于浏览器 localStorage，不上传任何数据。
